# Aide

| Tu veux… | Où aller |
|---|---|
| Signaler un bug | [Issues](https://github.com/KBL411/Engineer_Mercy/issues), modèle « Bug report » |
| Proposer une idée | [Issues](https://github.com/KBL411/Engineer_Mercy/issues), modèle « Feature request » |
| Corriger ou ajouter quelque chose | une *pull request*, voir [CONTRIBUTING.md](CONTRIBUTING.md) |
| Signaler une faille de sécurité | en privé, voir [SECURITY.md](SECURITY.md) |
| Installer l'outil | le tutoriel du [README](README.md) puis `npm run doctor` |

Ne colle jamais ton CV, tes rapports d'évaluation ou une clé d'API dans une issue : elle est publique.
